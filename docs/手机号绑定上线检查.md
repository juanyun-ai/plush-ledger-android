# 手机号绑定上线检查

当前源码已经实现：

- 手机号验证码注册和登录。
- 邮箱云账号绑定或换绑手机号。
- 本地模式验证手机号后升级为云账号，并自动合并本机账本。
- 验证成功后将手机号同步到 Supabase Auth、`profiles.phone` 和本机安全会话。

## 当前线上状态

- Supabase Phone Auth：已开启。
- 当前 SMS Provider：Twilio。
- App 客户端：已按 Supabase 官方 `sms` 和 `phone_change` 流程接入。
- 发布开关：`PHONE_AUTH_ENABLED` 默认是 `false`，公开安装包不会展示手机号登录、绑定或升级入口。
- 待确认：Twilio Account SID、Auth Token、Message Service SID、账户余额和中国大陆发送权限是否真实有效。

需要制作仅供验收的测试包时，显式执行：

```bash
./gradlew assembleDebug -PPHONE_AUTH_ENABLED=true
```

## 正式推送前必须通过

1. 中国大陆真实手机号能在 60 秒内收到 6 位验证码。
2. 邮箱账号绑定手机号后，Supabase Auth 和 `profiles.phone` 显示同一个 E.164 手机号。
3. 本地模式升级手机号后，原本地账目成功合并，且原本地数据仍保留。
4. 退出后使用同一手机号重新登录，能恢复同一用户和云端账本。
5. 同一手机号不能绑定两个不同的 Supabase 用户。
6. 验证码重发限制、异常提示和服务商费用预警正常。

未通过以上验收前，任何公开 release 构建都必须保持 `PHONE_AUTH_ENABLED=false`，版本说明不得宣传手机号能力。通过验收后，再单独开启入口并创建对应的线上版本记录。
